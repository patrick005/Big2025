## 2일차 · C 기초

### 헤더와 함수

`#include`는 전처리 단계에서 헤더 내용을 포함한다. 여러 헤더가 같은 헤더를 포함할 때는 헤더 가드로 중복 선언을 방지할 수 있다. 아래 예제의 `int main(void)`는 매개변수 없이 정수를 반환하는 프로그램 진입점이다.

### 메모리와 변수

폰 노이만 구조에서는 명령과 데이터가 메모리를 공유하고, 하버드 구조에서는 명령과 데이터의 저장 공간이 분리된다. C에서는 변수의 유효 범위와 저장 기간을 구분한다. 일반적인 지역 변수는 블록을 벗어나면 수명이 끝나고, 전역 변수는 프로그램 실행 내내 유지된다. 동적으로 확보한 메모리는 사용이 끝나면 `free`로 해제한다.

### 산술 연산 실습

다음 예제는 두 정수로 사칙연산과 나머지를 계산한다. 실습할 때는 두 번째 수에 0을 넣지 않고 각 결과가 `int` 범위 안에 드는 작은 정수를 사용한다.

```c
#include <stdio.h>

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2 || b == 0) {
        return 1;
    }

    printf("덧셈 %d\n", a + b);
    printf("뺄셈 %d\n", a - b);
    printf("곱셈 %d\n", a * b);
    printf("정수 나눗셈 %d\n", a / b);
    printf("나머지 %d\n", a % b);
    return 0;
}
```

복합 대입에는 `+=`, `-=`, `*=`, `/=` 등이 있다. `++a`는 증가한 값을, `a++`는 증가 전 값을 표현식의 결과로 사용한다. 증감 연산자는 대입 연산자보다 우선순위가 높다.

### 표기와 출력

| 예제 | 의미 |
| --- | --- |
| `100`, `0144`, `0x64` | 같은 정수 100을 각각 10진수, 8진수, 16진수로 작성 |
| `printf("%.2f", 2.718)` | 소수점 아래 두 자리까지 출력 |
| `10000000000LL` | 정수 리터럴의 자료형을 `long long`으로 지정. 출력 서식은 `%lld` |
| `3.141592F` | 실수 리터럴의 자료형을 `float`로 지정 |
| `%d`, `%c` | 문자 값을 정수 또는 문자로 출력. ASCII에서 대문자 A의 값은 65 |
